LINUX EXPLODE

Repositório Flatpak (x86_64 e ARM64) — hardware, sensores e EXPLODE BENCH.

Adicionar o repositório

flatpak remote-add --user --no-gpg-verify linuxexplode https://nbtech-prox.github.io/LinuxExplode/
flatpak install --user linuxexplode pt.linuxexplode.LinuxExplode

Actualizar

flatpak update --user

O gestor de aplicações do sistema passa a mostrar as actualizações deste repositório.

Ficheiros

Instaladores e checksums em github.com/nbtech-prox/LinuxExplode/releases.

O repositório não está assinado com GPG: usa --no-gpg-verify.
